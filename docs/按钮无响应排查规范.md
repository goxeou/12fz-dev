# 按钮点击无响应 — 排查与防范规范

> 制定: 2026-05-24 | 适用于 12FZ 程序开发组所有成员
> 本规范基于团队会议讨论由老板制定方向，chaogu-ai 整理为文。

---

## 一、核心原则

**"按钮点不动"不是Bug，是AI"幽灵逻辑"的外在表现**——代码语法没报错，但实际没绑定到界面。各自代码的前端表现各自负责。

---

## 二、检查事件绑定（最核心）

### 2.1 函数是否挂载？

在浏览器控制台直接输入函数名（如 `handleClick`）：
- 返回 `undefined` → 函数没暴露到全局，或框架绑定错误
- 返回函数体 → 绑定可能存在但没触发

### 2.2 DOM 是否动态生成？

| 场景 | 问题 | 正确做法 |
|------|------|---------|
| `innerHTML` 填充的按钮 | 普通 `onclick` 绑定会失效 | **事件委托**：`document.querySelector('父容器').addEventListener('click', (e) => { if(e.target.matches('.btn-class')) ... })` |
| 后端渲染/SSR 按钮 | 先检查元素是否存在页面源码中 | 确保 JS 初始化函数在 DOM 渲染后执行 |

### 2.3 框架特有陷阱

| 框架 | 常见错误 | 正确写法 |
|------|---------|---------|
| Vue | `methods` 写错成 `method` | 检查 `export default { methods: { handleClick() {} } }` |
| React | 忘了 `() =>` 传了函数引用 | `onClick={() => handleClick()}` 或 `onClick={handleClick}`（不要 `onClick={handleClick()}`） |
| jQuery | 绑在动态元素上 | 用 `$(document).on('click', '.btn', handler)` 替代直接 `.click(handler)` |

## 三、排查阻断点

### 3.1 控制台报错（红色）

脚本报错会阻塞后续代码执行。按顺序查：
1. **变量未定义** — `Uncaught ReferenceError: xxx is not defined`
2. **请求跨域** — `Access-Control-Allow-Origin` 相关的报错
3. **语法错误** — 缺少 `}`、分号等

**规则：** 合入前必须打开控制台确认**0个红色报错**。

### 3.2 `event.preventDefault()` 误用

- AI 为了"防表单提交"有时会阻止按钮默认行为，但又没写后续逻辑
- 检查：在 handler 里搜索 `.preventDefault()`，确认后面有实质代码

### 3.3 异步没等待

- AI 生成了 `async` 函数但没写 `await` → 你以为数据拿到了，实际还是 `Promise`
- 检查：所有 `async` 函数内部必须有 `await`，所有调用 `async` 函数的地方必须有 `await`（或 `.then()`）

## 四、AI 代码的固有缺陷

| 缺陷类型 | 表现 | 防范方法 |
|---------|------|---------|
| **选择器不匹配** | AI 写了 `.btn-primary` 但实际是 `#submitBtn` | 审查时对照实际页面 HTML 的类名/ID |
| **生命周期错位** | React `useEffect` 里绑定原生事件，但没做清理 → 重复绑定 | 检查有没有 `return () => { cleanup }` |
| **依赖缺失** | 用了 `jQuery` 但没引入 | 审查时检查页面加载的所有 script |
| **假绑定** | 写了 `$('.btn').click(function...)` 但按钮在之后才渲染出来 | 用事件委托替代直接绑定 |

---

## 五、验证技巧

### 5.1 临时测试法

AI 代码生成后，手动加一行 `alert('clicked')` 在点击处理函数开头：
- ✅ 能弹出 → 事件绑定正常，问题在内部逻辑
- ❌ 弹不出 → 事件绑定失败，优先排查绑定

### 5.2 Console 监听法

在 Elements 面板选中按钮（`$0`），执行：
```javascript
$0.onclick = (e) => console.log('clicked', e)
```
然后点击，看控制台有没有日志。

### 5.3 浏览器内置检查

- Elements 面板检查按钮的 Event Listeners 选项卡
- 看有没有挂载 click 事件
- 挂载在哪个元素上（是不是正确的目标）

## 六、强制检查清单

**合入前开发者必须自行验证（截图发群）：**

- [ ] 控制台 0 个红色报错
- [ ] 按钮点击有明确视觉反馈（或跳转/提交动作）
- [ ] 异步操作有 loading 状态或成功/失败提示
- [ ] 动态生成的元素使用事件委托而非直接绑定
- [ ] `alert('clicked')` 测试能弹出（最低标准）

**chaogu-ai 审查时额外检查：**

- [ ] 选择器名与实际 HTML 一致（非幻觉类名）
- [ ] `async`/`await` 链完整，无遗漏
- [ ] 框架生命周期绑定无重复/泄漏
