## 第五部分：支付体系

### 5.1 架构设计 — 插拔式支付渠道

```
┌─────────────────────────────────────────────────┐
│              12FZ 支付管理中心                    │
│  （国家-支付矩阵 / 默认全开 / 按需关闭）            │
├────────┬────────┬────────┬────────┬──────────────┤
│        │        │        │        │              │
│ 支付宝  │BNB Pay │PayPal  │12FZ代币│ 新支付X...   │
│ 插件    │ 插件   │ 插件   │ Gateway│ 插件         │
│        │        │        │        │ (1天接入)    │
└────────┴────────┴────────┴────────┴──────────────┘
```

**统一基类：** `SZ_Payment_Gateway` 继承 `WC_Payment_Gateway`
**新渠道接入：** 写一个类继承基类 + API密钥 = 1天上线

### 5.2 国家-支付管控矩阵

```
                ┌─── 中国 ─── 美国 ─── 日本 ─── ...
                │
  支付宝        │   ✅      ❌      ❌
  Binance Pay   │   ✅      ✅      ✅  ← 新增
  PayPal        │   ❌      ✅      ✅
  12FZ代币      │   ✅      ✅      ✅
  信用卡        │   ✅      ✅      ✅
  ⋮             │
```

- **默认全开**（所有支付方式对所有国家可用）
- 按需手动关闭（取消勾选即禁用）
- 用户结算时按收货国家自动过滤

### 5.3 支付排序规则

排序支持**按国家独立配置**：

| 规则 | 说明 |
|------|------|
| 全局默认排序 | 所有国家统一的排序 |
| 按国家定制 | 某国家单独设置排序（覆盖全局） |
| 使用人次排序 | 可选一键按支付量降序排列 |

**默认顺序：** 支付宝 → Binance Pay → PayPal → 12FZ代币 → 信用卡 → ...

### 5.4 数据库设计

```sql
-- 支付禁用表（默认全开，只存禁用的）
CREATE TABLE sz_12fz_disabled_payments (
    id         INT AUTO_INCREMENT PRIMARY KEY,
    country    VARCHAR(4)   NOT NULL,
    gateway_id VARCHAR(32)  NOT NULL,
    UNIQUE KEY uk_disabled (country, gateway_id)
);

-- 支付排序表
CREATE TABLE sz_12fz_payment_ordering (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    country     VARCHAR(4)   NOT NULL,
    gateway_id  VARCHAR(32)  NOT NULL,
    sort_order  INT          NOT NULL DEFAULT 0,
    UNIQUE KEY uk_order (country, gateway_id)
);

-- 支付使用统计
CREATE TABLE sz_12fz_payment_stats (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    country     VARCHAR(4)   NOT NULL,
    gateway_id  VARCHAR(32)  NOT NULL,
    usage_count INT          NOT NULL DEFAULT 0,
    updated_at  DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_stats (country, gateway_id)
);
```
