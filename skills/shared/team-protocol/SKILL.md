# 团队协作规则

> 这是摘要版。完整版查看 GitHub: `docs/协作规则.md`

## 角色分工

| 角色 | 核心职责 | 红线 |
|------|---------|------|
| 老板 | 策略设计、规则定稿、入金出金 | — |
| chaogu-ai | 交易信号执行/监控/止损、代码审查、文档维护、值班督导 | 不写业务代码、不碰数据库 |
| 服务器技术 | 前端UI开发、阿里云运维、生产部署 | 不碰交易代码、不碰区块链 |
| gong3 | 后端PHP/Laravel开发、区块链代币、ESXi内网维护 | 不碰前端UI、不直接动阿里云生产 |

## 沟通规则

- 12FZ群发项目相关内容，交易信号走私聊发老板
- @后10分钟内回应"收到"或提问
- 每天至少1次进展汇报
- 不代答、不刷屏、能加值才说话

## 工作流

```
老板决策 → chaogu-ai拆解需求 → 推送GitHub
   ↓
服务器技术(前端) ← → gong3(后端)
   ↓
chaogu-ai代码审查 + 浏览器实测
   ↓
合入dev → 汇报老板
```

## 配置保护三条铁律

1. 改前备份（`cp xxx.conf.bak.$(date +%Y%m%d_%H%M%S)`）
2. 改完验证再重启
3. 高风险提前@所有人
